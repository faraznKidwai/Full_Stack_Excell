Full-Stack Excel Editor & Card Viewer
We will build a full-stack web application consisting of:

Backend (Node.js/Express): A lightweight API server that manages the data in a SQL database and handles queries to the Yahoo Finance API.
Database (Prisma ORM + SQL):
Local Development: SQLite (file-based SQL, zero-install, extremely fast).
Production Deployment: PostgreSQL hosted on Supabase or Neon (both offer excellent free tiers).
Prisma ORM: Enables seamless transition between SQLite and PostgreSQL just by updating the database URL in the environment variables.
Frontend (React):
Admin Dashboard: Uploads Excel files, displays them in an editable grid, and saves the data as JSON to the database.
User View: Fetches the active data from the backend and displays each row as a premium visual card.
User Review Required
IMPORTANT

Yahoo Finance API Integration: Running this on the Node.js backend prevents CORS browser blocks and secures any API configurations. We'll outline an endpoint like /api/finance/:ticker to pull market details.
Zero-Config Database for Dev: Using Prisma with SQLite allows you to run SQL migrations and test schema queries locally with zero server installations. When pushing to production, you'll simply plug in a free PostgreSQL database URL from Neon or Supabase.

Proposed Changes
[NEW] 
Excell_Final/backend/prisma/schema.prisma
The Prisma database schema:

prisma

datasource db {
  provider = "sqlite" // changed to "postgresql" in production
  url      = env("DATABASE_URL")
}
generator client {
  provider = "prisma-client-js"
}
model ExcelRow {
  id        Int      @id @default(autoincrement())
  rowId     String   @unique // unique identifier for the row
  data      String   // JSON stringified row object
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
[NEW] 
Excell_Final/backend/server.js
An Express application with the following endpoints:

GET /api/rows: Fetch all rows from the database.
POST /api/rows: Overwrite/upsert the rows in the database.
GET /api/finance/:ticker: Fetch stock/market details from the Yahoo Finance API using yahoo-finance2 package.
[NEW] 
Excell_Final/frontend/src/utils/excelParser.js
Functions to parse the uploaded file buffer into worksheets and convert them to clean arrays of key-value objects.

[NEW] 
Excell_Final/frontend/src/components/AdminDashboard.jsx
Editable sheet grid with columns mapping, local sheet state management, and a "Save to DB" action to persist edits.

[NEW] 
Excell_Final/frontend/src/components/UserView.jsx
Fetches row data from the database and renders a responsive grid of Card components, showcasing additional real-time market data fetched via the Yahoo Finance API backend proxy.
